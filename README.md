# 智航绿脉 · Cloudflare 版

绿色航运决策比赛演示网站，使用 Cloudflare Pages 托管前端、Pages Functions 处理登录与公开海况。无需单独租服务器、购买域名或配置数据库。

访客使用比赛演示账号 **admin / 123456**，无需注册。

## 目录

```text
public/                 网站页面、脚本、样式、地图素材及静态路由配置
functions/              Cloudflare 登录、会话、退出、公开海况接口
package.json            本地开发与命令行部署命令
package-lock.json       锁定开发工具依赖版本
wrangler.toml           Cloudflare Pages 配置
.dev.vars.example       本地环境变量模板，不含真实密钥
CLOUDFLARE部署说明.md    GitHub 到 Cloudflare 的操作步骤
```

## 发布

将本目录的内容放在 GitHub 仓库根目录，在 Cloudflare **Pages** 连接该仓库。框架选 None，构建命令 `exit 0`，输出目录 **public**，项目根目录留空。`functions/` 必须与 `public/` 同级，不能只上传网页文件。

在 Cloudflare 项目设置中添加加密变量 **SESSION_SECRET**（至少 32 字符的随机值），再部署一次。`wrangler.toml` 中的 `name` 应与 Cloudflare 项目名一致；默认是 `ecovoyager-demo`。使用 Cloudflare 分配的 `*.pages.dev` 地址即可访问。

详见 [CLOUDFLARE部署说明.md](CLOUDFLARE部署说明.md)。Cloudflare 网页端直接拖拽 ZIP 不会编译本项目的 Functions，请使用 GitHub 集成或 Wrangler。

## 本地预览

Windows 双击 `启动本地预览.cmd`，或在本目录运行（Node.js 22 及以上）：

```powershell
node scripts/dev.mjs
```

打开 http://127.0.0.1:8788 ，账号 **admin / 123456**。本地预览无需安装依赖，使用与 Cloudflare 相同的登录、会话、海况接口代码；未配置密钥时仅为本次进程生成临时密钥。关闭终端停止服务，重启后重新登录。端口冲突可执行 `node scripts/dev.mjs --port=8789`。

需要 Cloudflare 本地模拟器时，执行 `npm ci`，复制 `.dev.vars.example` 为 `.dev.vars` 并填写密钥，再执行 `npm run dev:cloudflare`。发布仍使用 `npm run deploy`。

模型回归验证：`node --test`。

## 本次优化

- 模型 v7：沿球面航段计算风区最近间距；避让开启时检查常态风区，台风时要求至少 10 nm，无合格路径不推荐。
- 综合成本包含燃油、碳、租船时间及可选超时费用。到港期限仍作为硬约束。租船费用默认 4000 USD/day，均为可调整演示假设；旧价格设置保留原值，缺省时间费用为零。
- 保存价格后结果标为待更新；事件预览会先按最新价格生成。
- 新档案以 v2 完整快照保存原指标、航路和环境比较，不随模型升级重算。旧 v1 仅保存参数，单独标识，需明确点击重算，不伪造原结果。
- 报告包含推荐结论、约束、费用分项和航路/调速节油贡献。非版本化资源重新验证缓存，版本化地图长期缓存。

## 功能与数据

- 模型 v8 支持途中重规划：先将地图下方回放拖到途中，再触发台风或港口拥堵并应用推荐。已完成航段、时间、燃油保持不变，新事件仅替换剩余航程的情景，最多连续调整 24 次。已到港时不再重规划航路。
- 成本、耗时、碳排放使用三组独立零基线柱状图，柱顶显示数值，预算和期限以虚线标记。支持鼠标或键盘选择方案，地图同步更新；可切换经济、低碳、准时偏好，均先检查硬约束。准时偏好按可靠泊总耗时排序；存在相同靠泊窗口时用成本打破平局。
- 点击“生成一页决策简报”预览当前已应用结果，再打印或保存 PDF。包括航路、三方案、约束、成本分项、环境来源与途中决策点。未应用预览和待生成输入不会混入简报。
- 途中方案档案保存各段原始指标；恢复后定位到该次决策点，仍可重播全程。旧模型档案可查看原值，重新生成才升级计算。

- 选择船舶、设置到港要求、比较三种方案、改变环境并查看推荐变化。
- 洋流与浪高支持季节估算和 Open-Meteo Marine 公开模型快照；16 个区域采样点插值，联网异常自动回退。成功响应在边缘节点缓存 30 分钟，失败缓存 60 秒；缓存并非全球共用。
- 台风和拥堵是可交互模拟事件；地图船队、油耗、排放和成本均用于比赛演示，不用于实际航行。
- 航次档案和设置保存在各自浏览器的 localStorage，换设备不共享，清除网站数据会丢失。档案最多 50 条；达到浏览器容量限制时保留能存下的最新完整档案并提示。CSV 报告由浏览器直接下载。
- 登录采用 HttpOnly 签名 Cookie，有效期 8 小时；退出清除当前浏览器 Cookie。无服务端会话数据库，因此已复制的有效 Cookie 不会因单次退出立刻失效；更换 SESSION_SECRET 并重新部署可使旧会话失效。
- 演示账号是公开共享账号，不应在本系统保存敏感资料。Cloudflare Functions 和上游数据接口受各自套餐、配额和服务可用性影响。
